---
name: Coordinator pending tasks
description: Privacy and review rules for extracting and managing coordinator follow-up tasks.
---

Each coordinator owns a private task list. AI analysis is explicit and on demand: it may propose tasks, but a coordinator must confirm or dismiss each proposal. Coordinators can also add tasks manually. A task can be marked resolved only with a written resolution.

Only use published final meeting minutes within the coordinator's current scope, messages directly received by that coordinator or in groups they currently belong to, and received email from that coordinator's own mailbox. Recheck source access after the AI request before saving suggestions. Do not infer or invent a responsible person, deadline, or resolution.

**Why:** the user chose AI proposals with coordinator confirmation and manual entry; each source keeps its existing confidentiality boundary.

**How to apply:** keep analysis user-triggered, suggestions reviewable, and task/source access scoped to the current coordinator. Any scheduled analysis, cross-coordinator task sharing, or automatic assignment is a separate product decision.
