---
name: LMS publication notices
description: Keep course publication announcements and notification delivery consistent with course visibility.
---

On the first transition of an autodirigido course to published, create a Tablón announcement and an in-app notification for active users, excluding the publisher. Published courses currently have no narrower per-user audience, so the notice follows that visibility. Repeated publish requests must not create duplicate notices.

**Why:** The user asked that publishing a course trigger both an announcement and a notification.

**How to apply:** Keep the Tablón item and persistent notification in sync with the course's first publication. Preserve active-user filtering, route notifications to the courses section on web and mobile, and avoid duplicate delivery on retries.
