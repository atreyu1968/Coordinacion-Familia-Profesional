---
name: Academic assignments vs module membership
description: Distinguishes who teaches a module from who is enrolled in its collaboration space.
---

Academic coordination counts must derive from `teaching_assignments`, filtered to the active professional family and the selected academic year. Count each teacher–module pair once in both directions: modules per teacher and teachers per module. Show the assigned teachers from those same records.

`module_memberships` represents enrollments, coordinators, and forum moderators; it is not a substitute for teaching assignments and may legitimately contain a different set of users.

**Why:** counting assignment rows inflated module totals when a teacher had multiple center/group records, while module membership counts came from a different relationship and included self-enrollment and management roles.

**How to apply:** keep academic-year selectors and active-family filters consistent across both sides of an assignment report. Label membership lists separately from teacher assignments.
